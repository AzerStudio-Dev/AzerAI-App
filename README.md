## 🚀 Quraşdırma, Hazırlanma və İşə Salma

### 📥 İstifadəçilər üçün (Hazır Quraşdırıcı)
1. **AzerAI App Setup** faylını yükləyin və ya aşağıdakı linkdən son versiyanı götürün:
 👉 [Yükləyin](https://github.com/AzerStudio-Dev/AzerAI-App/releases)
2. Quraşdırıcını başladın.  
3. Quraşdırma təlimatlarını izləyin.  
4. Quraşdırma tamamlandıqdan sonra tətbiqi işə salın.  
5. Google AI və ya OpenAI API açarlarınızı əlavə edin.  
6. İstəyə bağlı olaraq lokal **LiveKit Server** və ya **AzerAI Agent** quraşdırın və başladın.  
7. AzerAI App istifadə etməyə başlayın.

### ⚙️ Geliştiricilər üçün (Mənbə Kodundan Quraşdırma və Build)
Layihəni lokal mühitdə qurmaq, müxtəlif əməliyyat sistemləri üçün paketləmək (build) və işə salmaq üçün aşağıdakı komandalardan istifadə edin:

1. **Asılılıqların quraşdırılması:**
   ```bash
   npm install
   ```

2. **Layihənin və UI-ın hazırlanması (Build):**
   ```bash
   npm run build
   ```
   ```bash
   npm run build:ui
   ```

3. **Əməliyyat sistemlərinə uyğun paketləmə (OS Build):**
   - Windows üçün:
     ```bash
     npm run build:win
     ```
   - Linux üçün:
     ```bash
     npm run build:linux
     ```
   - macOS üçün:
     ```bash
     npm run build:mac
     ```

4. **Tətbiqin işə salınması (Lokal/Desktop mühiti):**
   ```bash
   npm run start
   ```
   ```bash
   npm run desktop
   ```
   ```bash
   npm run electron
   ```
